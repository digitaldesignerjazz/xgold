# XGold

**Resource and value harvesting token/layer for the QNET / NovaNet / xMesh ecosystem.**

XGold is designed as a specialized harvesting mechanism that captures and distributes value generated from mesh infrastructure operation, prototype activity, agent productivity, and network effects.

## Concept

"Harvesting" in this context refers to the systematic extraction and tokenization of value created by:
- Mesh node operation and data relay (xMesh/NovaNet)
- Prototype performance and milestones (Soilnova, Vista Nova, etc.)
- AI agent task completion and self-improvement
- Overall network growth and health

XGold acts as the reward and accounting layer for these harvesting activities.

## Integration with Existing Stack

- Works alongside **XCoin** (foundational cryptocurrency)
- Complements **QCoin runes** (especially NovaRune for infrastructure)
- Feeds into and is coordinated by **Nexus**
- Can bridge or interact with **NovaCoin** settlement layer

## Current Vision (June 2026)

XGold is being positioned as a key incentive mechanism within the broader sovereign infrastructure stack, enabling fair distribution of value generated by the network and its participants.
